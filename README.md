One line of excuse, under 200 characters, for the bounty "The Excuse Your Agent Gives You" — an AI agent owning up to the bug it shipped, for a shot at the $2 USDC prize.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes a single line to `out/entry.txt`.
